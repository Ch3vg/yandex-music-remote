# Пульт YM Remote

Телефон открывает страницу Python-сервера: `http://<адрес-компьютера>:8001/`.

`npm run dev` поднимает Vite (порт 5173) только для вёрстки. Это не адрес телефона: WebSocket и API должны быть на том же origin, что и страница. Их отдаёт сервер на порту 8001.

`npm run build` пишет статику в `web/dist`. Её позже раздаёт Python.
