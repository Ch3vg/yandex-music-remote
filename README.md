# Yandex Music Remote

Мобильный веб-пульт (PWA) для управления десктопным приложением **Яндекс Музыки** на Windows по локальной сети.

Сервер на ПК подключается к официальному клиенту Яндекс Музыки через **Chrome DevTools Protocol (CDP)** и поднимает мобильный интерфейс с QR-кодом для быстрого входа с телефона. Библиотека («Мне нравится» и пользовательские плейлисты) загружается через API Яндекс Музыки, а воспроизведение, очередь, поиск, громкость и реакции управляются напрямую в окне десктопного приложения.

## Возможности

- **Управление плеером**: пауза/воспроизведение, переключение треков (включая свайпы обложки), перемотка, громкость, повтор (`off` / очередь / один трек), перемешивание, лайк и дизлайк.
- **Медиатека и плейлисты**: раздел «Мне нравится», карусель последних лайков, список плейлистов и быстрый локальный фильтр внутри плейлиста.
- **Поиск и очередь**: поиск треков через десктопный клиент, запуск сразу (`Включить сейчас`), постановка следующим (`Играть следующим`), добавление в конец очереди и просмотр живой очереди воспроизведения.
- **Мобильный PWA-интерфейс**: установка на главный экран iOS / Android, адаптивный градиент под обложку трека, управление из шторки уведомлений / экрана блокировки через Media Session API («Плеер в шторке»).
- **Лаунчер с QR-окном**: автоматически находит Яндекс Музыку, при необходимости перезапускает её с флагами CDP, поднимает сервер в Windows Job Object и показывает окно с QR-кодом и ссылкой.

## Требования

- **ОС**: Windows 10 / 11
- **Яндекс Музыка**: установленное десктопное приложение (`%LOCALAPPDATA%\Programs\YandexMusic`)
- **Python**: 3.11 или новее
- *(Опционально)* **Node.js 20+** — только если планируется изменять фронтенд в `web/` (`web/dist` уже собран и включён в репозиторий)
- *(Опционально)* модуль PowerShell **`ps2exe`** — для сборки автономного лаунчера `YandexMusicRemote.exe`

## Быстрый старт

### 1. Клонирование и установка окружения

```powershell
git clone https://github.com/Ch3vg/yandex-music-remote.git
cd yandex-music-remote

python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

### 2. Настройка `.env`

Скопируйте шаблон переменных окружения и укажите OAuth-токен Яндекс Музыки:

```powershell
Copy-Item .env.example .env
```

Заполните `.env`:

```dotenv
YANDEX_MUSIC_TOKEN=ваш_токен_яндекс_музыки
LOCAL_IP=
PORT=8001
CDP_PORT=9222
```

| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `YANDEX_MUSIC_TOKEN` | Да | — | OAuth-токен аккаунта для загрузки «Мне нравится» и плейлистов |
| `LOCAL_IP` | Нет | автоопределение | Принудительный IPv4-адрес компьютера в локальной сети для ссылки и QR |
| `PORT` | Нет | `8001` | Порт HTTP / WebSocket сервера пульта |
| `CDP_PORT` | Нет | `9222` | Порт отладки Chrome DevTools Protocol десктопной Яндекс Музыки |

### 3. Запуск пульта

Любой из способов ниже проверит/запустит Яндекс Музыку с отладкой CDP, поднимет сервер пульта и откроет окно с QR-кодом:

- Без консольного окна (двойным кликом в Проводнике): `launcher\start-ym-remote.vbs` или `cdp\start-cdp.bat`
- Из PowerShell:
  ```powershell
  .\start-ym-remote.ps1
  ```

Отсканируйте QR-код камерой телефона (телефон и ПК должны быть в одной Wi-Fi / локальной сети). Закрытие окна QR останавливает только сервер пульта — сама Яндекс Музыка продолжает играть.

### Сборка `YandexMusicRemote.exe` (опционально)

Если установлен PowerShell-модуль `ps2exe`, можно собрать оконный `.exe`-лаунчер с иконкой:

```powershell
Install-Module ps2exe -Scope CurrentUser
.\launcher\package.ps1
```

В корне проекта появится `YandexMusicRemote.exe`.

## Разработка

### Структура проекта

- `src/ym_remote/` — Python-бэкенд (FastAPI, WebSocket, CDP-сессия с очередью транзакций, клиент API Яндекс Музыки):
  - `models/` — неизменяемые доменные модели;
  - `schemas/` — Pydantic-схемы проводного протокола HTTP и WebSocket;
  - `services/` — бизнес-логика, координация опроса (`HeavyGate`) и политика воспроизведения;
  - `cdp/` — единая сессия `CdpSession`, очередь транзакций на одно окно и DOM-скрипты;
  - `yandex/` — асинхронная обёртка над `yandex-music`;
  - `net/` — обнаружение и ранжирование локальных сетевых адресов;
  - `interfaces/` — точка входа ASGI (`ym_remote.interfaces.asgi:app`), маршруты HTTP и обработчики WebSocket.
- `web/` — мобильный фронтенд на React 19 + TypeScript + Vite (`web/dist` раздаётся Python-сервером).
- `launcher/` — WinForms-лаунчер на PowerShell, VBScript-обёртка и скрипт упаковки в `.exe`.
- `cdp/` — вспомогательные `.bat`-скрипты запуска музыки с CDP и фонового перезапуска сервера.
- `tests/` — модульные и интеграционные тесты `pytest`.
- `application.md` и `spec/architecture.md` — подробная спецификация протокола и архитектуры.

### Полезные команды

```powershell
# Только запустить Яндекс Музыку с флагами CDP без сервера пульта
.\cdp\launch-ym-debug.bat

# Фоновый запуск/перезапуск сервера без окна QR (логи в cdp\server-cdp.log)
.\cdp\restart-server.bat

# Ручной запуск uvicorn в консоли
$env:PYTHONPATH = "src"; $env:PYTHONUTF8 = "1"
.\.venv\Scripts\python.exe -m uvicorn ym_remote.interfaces.asgi:app --host 0.0.0.0 --port 8001

# Запуск тестов
.\.venv\Scripts\python.exe -m pytest -v

# Разработка и пересборка фронтенда
npm --prefix web install
npm --prefix web run dev
npm --prefix web run build

# Подключение локальных Git-хуков (pre-commit / pre-push с автотестами и защитой веток)
.\scripts\install-hooks.ps1
```

- Поток слияний: **рабочая ветка (`feat/*`, `fix/*`, …) -> PR в `dev` -> PR в `master`**.
- Прямой `push` в `master` и `dev` запрещён; все PR проходят автотесты и проверку направления слияния (`branch-flow`), а статус автотестов (`pending` / `passed` / `failed`) публикуется на каждый коммит.

## Безопасность

- Сервер рассчитан на использование **внутри доверенной домашней локальной сети**: HTTP и WebSocket слушают `0.0.0.0` без аутентификации. Не пробрасывайте порт `8001` (и тем более `9222`) во внешнюю сеть.
- Секретный токен `YANDEX_MUSIC_TOKEN` хранится только локально в файле `.env` на ПК (исключён из Git) и никогда не передаётся браузеру телефона.
